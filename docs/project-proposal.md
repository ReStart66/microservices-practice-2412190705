# 汽车维修保养管理系统项目提案

## 项目名称

汽车维修保养管理系统

## 目标用户

- 车主：预约维修、查看进度和账单。
- 服务顾问：接车、创建工单、管理配件、生成账单。
- 维修技师：检测车辆、记录维修、提交完工。
- 学徒：执行分配任务、记录操作进度。
- 收银员：处理账单、收款和退款。

## 优先实现的业务场景

优先实现“车主预约接车并创建维修工单”：

车主提交预约 → 服务顾问确认并接车 → 创建维修工单 → 维修技师检测车辆 → 分配学徒协助 → 服务顾问处理配件出库 → 维修完成 → 生成账单 → 收银员收款 → 通知车主取车。

## 两个核心模型

### 1. Vehicle 车辆

计划字段：

- id：车辆编号
- ownerName：车主姓名
- plateNumber：车牌号
- brand：品牌
- model：车型
- mileage：当前里程

### 2. WorkOrder 维修工单

计划字段：

- id：工单编号
- vehicleId：车辆编号
- serviceAdvisorId：服务顾问编号
- technicianId：维修技师编号
- status：工单状态
- faultDescription：故障描述
- createdAt：创建时间
- completedAt：完成时间

## 本周范围

本周只完成 Spring Boot 工程基础框架、运行接口、健康检查和启动测试。暂不实现 Service、Repository、数据库和完整业务功能。
